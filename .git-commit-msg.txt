Fix: 安装日志持久化 + 日志页"安装日志"标签

问题: 全新用户 (无 uv/npm/astrbot) 一键安装失败时, 前端提示"去看日志",
但日志页只有服务日志 (wechat/astrbot/qr), 安装日志只存内存 (弹窗关闭即丢),
用户看到三个日志页全空, 无法得知失败原因。

修复:
- 安装日志持久化到 logs/install.log (SetInstallLogPath 注入, 与主日志同目录)
- runCmd 的 stdout/stderr 增量读取同时写入 install.log (npm/clone/git 输出全保留)
- 日志页新增"安装日志"标签 (LogsPage SERVICES 加 install)
- /api/logs?service=install 读取 install.log (logsPath 支持 install)

实测: 模拟缺 wechat-bot 触发安装 → install.log 实时写入
([env] → [clone] → Cloning into...) → 日志页可实时查看。
